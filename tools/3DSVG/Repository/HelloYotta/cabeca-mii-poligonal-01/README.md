# Cabeça Mii poligonal 01

Um único modelo de estudo visual: cabeça e rosto com proporções inspiradas nos Miis e superfícies facetadas. Geometria própria, sem extrair assets Nintendo. Partes separadas para futura personalização. Frente: -Y no Blender. Sem corpo, esqueleto ou animações; não representa ainda uma peça integrada ao rig compartilhado.

Formatos: GLB, FBX, OBJ/MTL e projeto Blender. Previews transparentes frontal e três quartos representam o mesmo modelo. Materiais de cores sólidas; não há texturas externas necessárias.
