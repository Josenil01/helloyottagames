# Avatar Mii / Kenney 01

Um único personagem de estudo visual: a cabeça anterior preservada e escalada uniformemente, com corpo original inspirado nos volumes compactos dos Mini Characters Kenney. Sem extração de malhas Nintendo ou Kenney. Formatos GLB, FBX, OBJ/MTL e Blender; previews transparentes frontal e três quartos. Frente: -Y no Blender. Materiais sólidos, sem texturas externas.

Esta amostra é estática, sem esqueleto ou animações; não representa a implementação do sistema de rig compartilhado. O modelo anterior somente de cabeça permanece intacto.
