# Avatar quadrado 01

Estudo original inspirado na imagem fornecida. Uma malha, um material, atlas de 64x64 pixels. Olhos, sobrancelhas, nariz e boca na textura; cabelo formado por volumes geométricos incorporados à malha final. Sem esqueleto ou animações nesta amostra. Frente -Y no Blender. GLB com textura incorporada, FBX, OBJ/MTL e Blender. A redução de objetos não elimina o custo de vértices, materiais, animação e renderização; números medidos em validation.json.
