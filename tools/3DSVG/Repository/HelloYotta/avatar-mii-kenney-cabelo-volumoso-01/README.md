# Avatar com cabelo volumoso

Mesmo personagem de avatar-mii-kenney-01. Apenas a malha separada de cabelo foi alterada, com maior volume na coroa e topete lateral. Cabeça, rosto, corpo, materiais e roupas preservados. Conferência por comparação dos dados geométricos e transformações das 26 malhas restantes. Modelo estático, sem rig. GLB, FBX, OBJ/MTL e Blender; duas vistas do mesmo modelo.
